## In this Mini-project i made a Traffic Light simulation using LED, and joystick, the traffic light is controllable using joystick sequentially.

https://github.com/user-attachments/assets/e4ee9e33-f990-4fec-9ef1-86f06a2dc71d

Tools:
- 1x Arduino Uno R3
- 1x BreadBoard
- Bunch of Jumper Cable (M2M & M2F)
- 3x LED Each Red, Yellow, Green
- 3x Resistors 220 Ohm

###CONNECTIONS!<br>
LED    >    2,3,4<br>
Minus  >    GND via Resistor<br>

- Joystick<br>
GND    >    GND<br>
VCC/5v >    5V<br>
VRx    >    A0<br>
SW     >    7<br>
